# Starknet

This directory contains the contract related code for Stork on Starknet.

 - [Contract](contracts)
 - [SDK](sdks/stork_starknet_sdk)
 - [Examples](examples)

The off-chain pusher lives in
[apps/chain_pusher/pkg/starknet](../../apps/chain_pusher/pkg/starknet).

Deployment and administration are handled by a local CLI built on
[starknet.js](https://github.com/starknet-io/starknet.js), which is kept out of this repo along
with deployment records.
